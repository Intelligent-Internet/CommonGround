# Optional NanoBot CG Skill Fragment

This directory is optional. It only shows how NanoBot can load the runtime-neutral `cg` skill by adding the CommonGround virtualenv to NanoBot's exec path.

Generic BYOA work-memory reporting and BYOA conversation-worker admission are documented under `docs/en/guides/` and `examples/byoa/`. They do not require NanoBot.

Use this fragment only when NanoBot is the harness you have already chosen. It is not the default BYOA setup path and it does not cover NanoBot gateway or managed-continuation behavior.
