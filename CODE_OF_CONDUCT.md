# Code Of Conduct

## Our Standard

We expect contributors to keep discussions respectful, technical, and focused on the work. Good participation includes:

- using clear and considerate language;
- accepting responsibility for mistakes;
- giving and receiving technical feedback constructively;
- respecting maintainer decisions about scope and project direction.

Unacceptable behavior includes harassment, threats, personal attacks, repeated disruption, or publishing private information without permission.

## Enforcement

Maintainers may edit or remove comments, close issues, reject contributions, or block participants when behavior harms the project community.

Report conduct concerns privately through maintainer contact in GitHub or the linked community channel. If no private path is available, open a public issue titled `Conduct contact request` with no personal details so maintainers can move the report to a private channel.
